Privacy Policy

Moises Keyboard Shortcuts — Chrome Extension

Last updated: February 22, 2026

Summary

This extension does not collect, store, or transmit any user data. It runs entirely in your browser.

Data collection

This extension collects no data of any kind. It does not use cookies, analytics, tracking, or any third-party services.

How it works

The extension injects a content script on studio.moises.ai that listens for keyboard events and clicks the corresponding mute/solo buttons in the page. All processing happens locally in your browser tab. No information ever leaves your device.

Permissions

The extension requires host access to studio.moises.ai solely to inject the keyboard shortcut script. This permission is not used for any other purpose.
